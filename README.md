## 🚀 Key Features

- **Pixel-Accurate Premium Aesthetics:** Brand color palette (Deep Teal `#064E49`, Primary Teal `#008F83`, Turquoise `#31D6C5`), glassmorphism, responsive grid layouts, and typography powered by Google Fonts (Plus Jakarta Sans & Outfit).
- **Comprehensive Hero Search:** Real-time multi-parameter search across Location, Property Type, Budget range, and BHK configuration.
- **Legal & Approval Badges:** CMDA Approved, DTCP Approved, RERA Approved, Bank Loan Available up to 90%, Gated Community, and 24/7 Support.
- **5 Category Sections:** Residential Plots, 2 BHK Homes, 3 BHK Homes, Luxury Villas, Land + Construction.
- **4 Featured Reference Properties:** Avadi 2 BHK House, Thiruninravur Plots, Veppampattu 2 BHK Villa, Siruseri 3 BHK Villa.
- **Floating AI Property Advisor:** Intelligent conversational assistant parsing natural language queries and providing live property recommendations.
- **Reducing-Balance EMI Calculator:** Financial modeling tool with sliders for loan amount, tenure, and interest rate.
- **Interactive Property Details:** Multitab view (*Overview, Gallery Lightbox, Location Map, Amenities, Nearby Landmarks, Floor Plan, Reviews*).
- **Verified Brochure Downloads:** 4-digit SMS OTP verification simulation before granting high-res PDF brochure access.
- **Side-by-Side Comparison Matrix:** Compare up to 4 properties on technical specifications, pricing, and approvals.
- **Free Doorstep Cab Site Visit:** Easy scheduling modal with instant CRM booking.
- **User Authentication & Personalized Experience:** 
  - Dynamic header with `Hi, [Actual User Name]`
  - 9-item profile dropdown
  - User-specific Wishlist, Saved Properties, and Enquiry tracking
  - Admin CRM panel for managing property listings and lead pipeline.

## 📦 Getting Started

### Prerequisites
- Node.js (v18 or higher recommended)
- npm / yarn / pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/srilakshman73/PERFECT-HOMES-DEVELOPERS.git

# Navigate into the project folder
cd PERFECT-HOMES-DEVELOPERS

# Install dependencies
npm install

# Start the local development server
npm run dev
```

### Production Build

```bash
# Build the production bundle
npm run build

# Preview the production build locally
npm run preview
```

---

## 🌐 Deployment on Vercel

1. Push your changes to the `main` branch on GitHub.
2. Go to [Vercel Dashboard](https://vercel.com/new).
3. Import the `srilakshman73/PERFECT-HOMES-DEVELOPERS` repository.
4. Framework Preset: **Vite**
5. Root Directory: `./`
6. Build Command: `npm run build`
7. Output Directory: `dist`
8. Click **Deploy**.
